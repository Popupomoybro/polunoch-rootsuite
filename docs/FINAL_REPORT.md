# FINAL_REPORT.md — итоговое состояние проекта (24.11.2026)

## 1. Короткий ответ на главный вопрос

**Root на iPhone 12 mini / iOS 26.2 beta 1 (23C5027f) НЕ получен.** ROOTSTATE NO во всех прогонах. Публичного пути к root для этой конфигурации **не существует** (VERIFIED): Dopamine 3.0.13 поддерживает A14 только до iOS 17.3.1 (iOS 26 — только A12/A13), palera1n — только A8–A11, понижение прошивки невозможно.

## 2. Что реально достигнуто (доказано)

### 2.1. Паника 112477 — от «иногда падает» до полной локализации (VERIFIED)
* 7 паник сопоставлены с образом ядра (UUID сматчен во всех): одна инструкция `casa x8,x9,[x0+8]` (kernelcache файл 0x1026418) в пути `lock_mtx.c:319`, вызывающий kext IOSurface 393.2.9, поле `[obj+0x148]`, `far = x0+8`.
* Маппинг слайдов выведен и сверен на четырёх разных загрузках.
* **Воспроизводимость по команде**: модуль `112477 V_BIG unit3 direct` даёт панику за один запуск.
* Исправлена ошибка предыдущего аудита (поле `+0xd8` → `+0x148`).
* Отрицательные результаты зафиксированы: racer unit6 (36 раундов чисто), KCE-свип имён (мёртв на 26.2b1), POST-шторм-теория (неconfirmirована).

### 2.2. Веб-верификация ландшафта (VERIFIED со ссылками)
* 6 CVE подтверждены как реальные (Apple Security Releases, GitHub, NVD, CISA KEV): 46285 (root-LPE), 112477 (наш PoC-базис), 64788 (A14-tested PoC), 65330 (PAC bypass), 112611, 86950 (KEV).
* Публичная цепочка 64788 → kernel r/w → 65330 → root **не завершается** на iOS 26 (zone sequestration — по собственному README PoC).
* Единственный применимый CVE с описанием root — **CVE-2025-46285** (фикс в 26.2 release; наша beta 1 собрана раньше → уязвима в принципе). Публичного PoC нет.
* Проверка диversifier'а 65330 в нашем ядре: `0x307a` — номер строки в `handle_share_range`, не PAC → применимость UNVERIFIED.

### 2.3. Приложение (инженерно)
* Стабильность защищена: тег `stable-2211-working`, бэкап 290 файлов, рабочая сборка на десктопе.
* Найден и исправлен **класс дефектов**: строки-литералы с не-ASCII не попадали в бинарник (ломали табы Diagnostics/About и кредитную строку). Весь `AppDelegate.m` — чистый ASCII, проверка по бинарнику.
* Stage-1 редизайна: табовый каркас (Modules/Log/Diagnostics/About) **на рабочей базе** — запуск работает, лог переехал в свой таб (TextKit снят с per-line пути), Diagnostics несёт verified-факты и живой ROOTSTATE-probe.

## 3. Что не удалось и почему

| задача | почему |
|---|---|
| Контролируемое разыменование (канарейка в far) | 6/7 паник — NULL-вариант; P4 вероятностный (1 паника в истории); размер класса объекта неизвестен (символов в ядре нет) |
| Root | ни один применимый вектор не даёт примитиву без дополнительных стадий; публичных PoC под root на этой конфигурации нет |
| Порты PoC 64788/65330 в RootSuite | следующий этап (64788 — диагностический модуль с оракулом; 65330 — не подтверждён на нашей сборке) |
| Stage-2/3 материалов (стекло) | после подтверждения stage-1 на устройстве; базовый риск — краши стеклянной оболочки, поэтому поэтапно |
| Скриншоты экранов | нужны с устройства (у пользователя) |

## 4. Следующие шаги (приоритет)

1. **Device:** серия P4 (ловить APP-MAPPING) + серия unit3 (статистика вариантов) — `.ips` + логи.
2. **Код:** диагностический модуль 64788 (оракул `0xe00002c2 → 0xe0002be`, PoC тестирован на A14) — проверка совместимости известного метода с нашей сборкой.
3. **Код:** stage-2 материалов поверх `glass-stage1` после подтверждения stage-1.
4. **Ресёрч:** targeted-разбор CVE-2025-46285 (sandbox-extension expiry — первый кандидат; у нас уже есть READ-grant на /System).
